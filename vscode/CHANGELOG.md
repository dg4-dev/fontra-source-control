# Changelog

## 0.1.0

The first release.

- **Open Preview to the Side**: the glyph or the kerning of the file in the editor, redrawn while you type
- **Open Changes as Drawing**: the changes of a glyph or kerning file drawn the same way as in the Fontra Source Control plugin. Start it from a file in the Source Control view, the editor title, the Explorer, a diff editor or a commit in the Timeline
- **Open Changes from History…**: pick a commit that changed the file and see what it changed
- UFO / designspace, `.fontra`, `.glyphs` and `.glyphspackage` fonts
- Follows VS Code's color theme and display language (English, 简体中文, 繁體中文, 日本語, Deutsch, Nederlands, Français, Italiano, Español, Português, Русский in the panels; English and Japanese in commands and messages)
